# Week 5 — Python

This folder contains my Week 5 Python exercises from the AWS re/Start program.

## What I Learnt

- Python basics (variables, data types, loops, conditionals)
- Working with strings and lists
- Reading and writing JSON files
- Using `subprocess` to run system commands
- Building small automation scripts

## Files Included

| File | Purpose |
|------|---------|
| `hello-world.py` | First Python script |
| `conditionals.py` | If/elif/else practice |
| `while-loop.py` | While loop practice |
| `for-loop.py` | For loop practice |
| `caesar-cipher.py` | Encryption exercise |
| `net-charge.py` | Insulin charge calculation |
| `calc-weight-json.py` | Molecular weight using JSON |
| `jsonFileHandler.py` | JSON file reader function |
| `sys-admin.py` | Running system commands with subprocess |
| `insulin.json` | Data file for the insulin exercises |

## What I Learned

Writing Python scripts helped me understand how to automate tasks, read data files, and debug errors systematically — skills that are key for DevOps and cloud engineering.
