# AWS re/Start Journey

This repository documents my hands-on learning journey through the AWS re/Start program.

I am using this journey to build practical skills in cloud computing, Linux, networking, security, AWS services, and infrastructure.

## How I Am Learning

My approach is simple:

**Learn → Understand → Build → Troubleshoot → Improve → Document**

The goal is to understand the concepts through practical work rather than simply completing labs or memorizing commands.

I also document mistakes and troubleshooting experiences because they are part of learning how to work with cloud and Linux environments.

## Week 1–2: Cloud Foundations & Linux

I started by learning the fundamentals of cloud computing and AWS, then applied those concepts by launching and working with a Linux EC2 instance.

The practical work included:

* AWS EC2 and SSH
* Linux filesystem navigation
* Users and groups
* File ownership and permissions
* `chmod` and `chown`
* File archiving with `tar`
* Pipes, `grep`, and `tee`
* Linux processes and process management
* System monitoring with `top`, `df`, and `du`
* Linux services with `systemctl`
* Troubleshooting real command and permission errors
